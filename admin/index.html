Як налаштувати хостинг та адмінку на GitHub

1 Створіть репозиторій на GitHub:

Зайдіть на github.com, створіть новий публічний репозиторій (наприклад, garland-landing) та завантажте туди всі файли проекту.

2 Увімкніть безкоштовний хостинг (GitHub Pages):

У репозиторії перейдіть у Settings → Pages → Source: виберіть Deploy from a branch, гілку main, папку / (root) і натисніть Save. Через 1-2 хвилини ваш сайт буде доступний в інтернеті!

3 Створіть токен для адмінки:

На GitHub відкрийте Settings → Developer Settings → Personal Access Tokens → Tokens (classic). Натисніть Generate new token, вкажіть назву (наприклад, LumiAdmin), поставте галочку repo і натисніть Generate.

4 Введіть дані вгорі цієї адмінки:

Вкажіть ваш GitHub Username, назву репозиторію та токен, і натисніть "Зберегти налаштування в браузері". Тепер кнопка "Опублікувати на сайт" автоматично оновлюватиме ціни на сайті!
