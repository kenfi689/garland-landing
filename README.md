# LumiGarland — Лендинг з адмін-панеллю та хостингом на GitHub

Професійний лендинг для продажу вуличної гірлянди-бахроми 105 LED (арт. 6МBY) з динамічним завантаженням цін, інтерактивним калькулятором, живою анімацією гірлянди та повнофункціональною адмін-панеллю з прямою інтеграцією в GitHub.

---

## 🚀 Швидкий запуск хостингу на GitHub (3 кроки)

### Крок 1. Створіть репозиторій на GitHub
1. Відкрийте [github.com/new](https://github.com/new)
2. Введіть назву репозиторію (наприклад, `garland-landing`)
3. Залиште репозиторій **Public** (Публічним) і створіть його.

### Крок 2. Надішліть файли проекту у ваш репозиторій
Виконайте в терміналі папку проекту:

```bash
git remote add origin https://github.com/ВАШ_ЛОГІН/НАЗВА_РЕПОЗИТОРІЮ.git
git push -u origin main
```

*(Якщо ви використовуєте Windows PowerShell, `git` уже встановлено в системі)*

### Крок 3. Увімкніть безкоштовний хостинг (GitHub Pages)
1. У вашому репозиторії на GitHub перейдіть у вкладку **Settings** (Налаштування) → розділ **Pages** (ліворуч).
2. У пункті **Build and deployment → Source** виберіть:
   - **GitHub Actions** (автоматичний деплой через готовий `.github/workflows/deploy.yml`)  
   *АБО*
   - **Deploy from a branch** → виберіть гілку `main` і папку `/(root)`, після чого натисніть **Save**.
3. Зачекайте 1 хвилину — у верхній частині з'явиться посилання на ваш опублікований сайт:  
   `https://ВАШ_ЛОГІН.github.io/НАЗВА_РЕПОЗИТОРІЮ/`

## 🛠️ Як користуватися адмін-панеллю

Адмінка доступна за адресою:  
`https://ВАШ_ЛОГІН.github.io/НАЗВА_РЕПОЗИТОРІЮ/admin/`  
*(або відкрийте файл `admin/index.html` локально)*

### Як увімкнути публікацію з адмінки в один клік:
1. **Згенеруйте токен на GitHub**:
   - Перейдіть за посиланням: [github.com/settings/tokens/new](https://github.com/settings/tokens/new)
   - У полі **Note** напишіть: `Admin`
   - У розділі **Select scopes** поставте лише одну галочку: `repo`
   - Натисніть **Generate token** внизу та скопіюйте згенерований токен (`ghp_...`).
2. **Введіть дані в адмін-панелі**:
   - **Власник GitHub**: ваш логін (наприклад, `alexander`)
   - **Репозиторій**: назва вашого репо (наприклад, `garland-landing`)
   - **Токен**: вставте скопійований `ghp_...`
   - Натисніть **"Зберегти налаштування в браузері"**.
3. **Редагуйте та публікуйте**:
   - Змінюйте акційну ціну, гуртову ціну, стару ціну, залишок на складі або текст.
   - Натисніть **"🚀 Зберегти та опублікувати на сайт"**.
   - Адмінка відправить комміт безпосередньо у ваш GitHub-репозиторій. GitHub Pages автоматично оновить сайт для всіх клієнтів за 30–60 секунд!

## 📁 Структура проекту

- `index.html` — Головна сторінка лендингу.
- `styles.css` — Стилі темної та святкової теми оформлення.
- `script.js` — Логіка калькулятора, вітрини, генерації ліній гірлянди та відправки замовлень.
- `data.json` — Файл конфігурації, який контролює ціни, залишки та контактні дані.
- `admin/`
  - `index.html` — Сучасна безсерверна адмін-панель з прямою синхронізацією через GitHub API.
  - `decap.html` — Альтернативна Decap CMS (для користувачів Netlify Git Gateway).
  - `config.yml` — Конфігурація для Decap CMS.
- `.github/workflows/deploy.yml` — GitHub Actions сценарій автоматичної публікації на GitHub Pages.
- `images/` — Фотографії товару та оформлення фасадів.
